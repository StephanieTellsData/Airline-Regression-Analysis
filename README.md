# Airline Regression Analysis

## Project Overview

This project investigates factors influencing airline operating costs across six airlines over a 15-year period using statistical analysis techniques in Microsoft Excel. Client requested a model to predict airline costs.

The analysis applies descriptive statistics, trend analysis, correlation analysis, and regression modelling to identify predictors of airline operating costs and recommend a model that can be used reliably to predict future costs.

---

## Objectives

- Analyse airline operating cost trends
- Examine relationships between operational variables
- Develop regression models
- Evaluate statistical significance of predictors

---

## Dataset Variables

- Airline
- Year
- Output
- Fuel Price
- Load Factor
- Cost (thousands)

Dataset Coverage:

- 6 airlines
- 15 years

---

## Statistical Techniques Applied

- Descriptive Statistics
- Correlation Analysis
- Trend Analysis
- Simple Linear Regression
- Multiple Linear Regression

---

## Key Findings

- Output demonstrated the strongest relationship with airline operating costs.
- Trend analysis supported the use of regression modelling.
- Multiple Linear Regression was selected to evaluate simultaneous effects of operational and economic factors.
